## Features
- Calculates the average of two integers.
- Calculates the average of three integers.
- Calculates the average of two floating-point numbers.
- Uses function overloading to perform different calculations with the same function name.

## Concept Used
**Function Overloading:** It allows multiple functions to have the same name but different parameters (number or data types). The compiler selects the appropriate function based on the arguments passed.

## Output
```text
-----Students Result-----
Average of Two integer: 3
Average of Three integer: 6
Average of Two Float: 5.5
```
