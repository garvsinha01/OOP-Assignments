## Features
Creates an Employee object with a name and ID.
Displays employee details.
Uses a constructor to initialize employee data.
Uses a destructor to perform cleanup when the object is destroyed.
Demonstrates automatic constructor and destructor calls.

## Concepts Used
Class and Object – Employee is a class and e1 is its object.
Encapsulation – Employee data members are declared as private.
Constructor – Initializes the employee's name and ID when the object is created.
Member Function – display() is used to show employee information.
Destructor – Automatically executes when the object goes out of scope.
Access Specifiers – private and public are used to control access to class members.
