## Features
Creates a University base class containing student details.
Creates a student derived class that inherits from University.
Stores and displays student name, age, and mobile number.
Stores and displays roll number and branch.
Demonstrates single inheritance in C++.
Uses separate member functions to display university and student information.

## Concepts Used
Class and Object – University and student are classes, while s1 is an object of the student class.
Inheritance – The student class inherits from the University class using public inheritance.
Base Class – University acts as the base/parent class.
Derived Class – student acts as the derived/child class.
Single Inheritance – One derived class (student) inherits from one base class (University).
Member Functions – display() and info() are used to display the data.
Data Members – Variables such as name, age, Mobile_Number, rollno, and branch store student information.
