## Features
* Uses C++ Function Templates.
* Swaps two values using a generic function.
* Supports different values of the same data type.
* Uses a temporary variable to exchange values.
* Promotes code reusability and reduces code duplication.

## Concepts Used
* Function Templates: Allows a single function to work with different data types.
* Generic Programming: Enables reusable code.
* Temporary Variable: Stores a value temporarily during swapping.
* Assignment Operator (=): Assigns values to variables.
* Input/Output (cout): Displays values before and after swapping.
* Swap operator
